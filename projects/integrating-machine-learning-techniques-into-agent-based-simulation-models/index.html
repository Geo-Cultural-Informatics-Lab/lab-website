Overview

Integrating Machine Learning Techniques into Agent-Based Simulation Models develops methods for making urban agent-based simulations more behaviorally realistic, data-driven, and sensitive to agent heterogeneity. The project addresses a central limitation of many ABMs: agents are often governed by hand-crafted rules or assumed utility functions, even when the real behavioral logic behind mobility, activity choice, or spatial interaction is only partially observed. The project uses machine learning to learn agent behavior from empirical mobility data and then embed that behavior within simulation models.

In one line of work, inverse reinforcement learning is used to replace manually specified daily-routine rules with reward functions learned from GPS trajectories in Jerusalem. These learned behavioral mechanisms are then integrated into an epidemiological ABM calibrated to COVID-19, showing how machine-learned mobility routines can affect simulated contagion patterns, quarantine dynamics, and spatial transmission networks. A second line of work extends this approach using graph neural networks to generate geospatial trajectories under incomplete data conditions.

By combining a GPS-based travel survey with building-level GIS data, the project learns mobility rewards over an urban building network and generates synthetic yet plausible daily trajectories. More recent work explores large language models as tools for generating profile-specific mobility trajectories, comparing supervised transition-matrix constraints with more autonomous prompt-driven generation. The broader contribution is methodological: the project shows how GeoAI, inverse reinforcement learning, graph learning, and LLM-based trajectory generation can be used to build ABMs that are less arbitrary, more empirically grounded, and better able to represent heterogeneous urban populations.

It supports applications in spatial epidemiology, transportation, emergency planning, and urban policy simulation.
