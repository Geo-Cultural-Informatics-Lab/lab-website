# Geo-Cultural Informatics Lab Visual Identity

This file is generated by `scripts/build_site.py` so it stays in sync with the website.

## Core Idea

The brand is organized around the same three-part system as the logo:

- Culture
- Space
- Information

The website should feel academic, spatial, computational, and human-facing. Color should clarify this structure rather than decorate every surface.

## Semantic Color System

| Role | Color | Hex | Use |
| --- | --- | --- | --- |
| Culture | HUJI burgundy | `#9A1732` | Culture, people, community, primary emphasis |
| Space | HUJI teal | `#168B98` | Spatial forms, morphology, patterns, relations, processes, links |
| Space support | HUJI mint | `#4EC4A3` | Diagrams, subtle spatial accents |
| Space anchor | Deep green | `#006A60` | Section headings, spatial detail emphasis |
| Information | HUJI blue | `#249FC1` | GIS, maps, data, code, computation, methods |
| Paper | Warm paper | `#F7F4ED` | Page background |
| Surface | Warm white | `#FFFDF8` | Cards, panels, header/footer |
| Ink | Near black | `#171717` | Main text |
| Muted | Blue-green gray | `#405F64` | Metadata, summaries, affiliations |

## Typography

- Primary typeface: `Source Sans 3`
- Technical accent typeface: `IBM Plex Mono`
- Fallbacks: Aptos, Segoe UI, Arial, Helvetica, sans-serif

Use Source Sans 3 for headings, body text, navigation, cards, and buttons. Use IBM Plex Mono only for binary/code/data motifs or small technical accents.

## Usage Rules

- Use teal as the default link and spatial identity color.
- Use burgundy sparingly for culture and important actions.
- Use blue for information/computation cues.
- Use mint and deep green for spatial details and supporting accents.
- Keep pages mostly calm: warm paper background, warm white surfaces, dark text.
- Avoid gradients, decorative blobs, and color-heavy sections.

## Homepage Hierarchy

The first screen should establish the lab idea before showing activity feeds:

- Logo, affiliation, lab name, and the hero summary lead.
- Culture, Space, and Information cards explain the framework using the logo colors.
- A single Featured from the Lab panel rotates projects, people, publications, and LinkedIn updates.
- Contact follows as a compact secondary band.

## Inner Page System

- Main index pages use a shared page intro: context label, title, short sentence, and a restrained accent.
- Project pages use the full three-color system because projects commonly span culture, space, and information.
- People pages use culture emphasis because members and collaborators represent activity, community, and interpretation.
- Publication pages use information emphasis because they foreground methods, data, maps, encoding, and knowledge generation.
- Do not assign individual projects to a single triad component unless the content explicitly requires it.
