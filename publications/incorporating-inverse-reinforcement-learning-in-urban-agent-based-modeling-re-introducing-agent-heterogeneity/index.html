Summary

This article addresses a recurring limitation in urban agent-based modeling: the difficulty of defining realistic behavioral rules for heterogeneous agents. Many agent-based models rely on hand-crafted utility functions or rule sets, but these choices can be arbitrary when detailed behavioral knowledge is unavailable. The paper proposes using inverse reinforcement learning to infer reward functions from observed mobility behavior, thereby replacing manually specified decision rules with data-driven behavioral representations.

A central contribution is the profile-based design of the learning process. Rather than assuming all agents respond to the urban environment in the same way, the method estimates reward functions for different agent profiles, allowing heterogeneous populations to express distinct mobility preferences and routines. The implementation uses GPS trajectory data from Jerusalem and applies the learned behavior within an epidemiological urban agent-based model calibrated to COVID-19.

The model includes a comprehensive feature matrix and a trajectory termination procedure based on empirically derived discounting so that simulated daily routines better match real-world trajectory lengths. The results show clear differences between inverse-reinforcement-learning-augmented and non-augmented simulations. They also show that the spatial structure of the city matters: treating the city as a unitary system obscures differences that emerge across regions and profiles.

The article contributes to GeoAI and urban simulation by showing how machine learning can improve behavioral realism while keeping the model interpretable enough to examine how heterogeneous agents respond to urban space.
