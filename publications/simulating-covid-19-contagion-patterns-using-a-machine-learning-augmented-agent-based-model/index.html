Simulating COVID-19 contagion patterns using a machine-learning-augmented agent-based model

Zi Hen Lin, Yair Grinberger, Daniel Felsenstein

Summary

This chapter uses COVID-19 contagion modeling to demonstrate how machine learning can be integrated into agent-based models in order to improve behavioral realism. It starts from the problem that many epidemiological simulations treat behavior as fixed or overly simplified, even though people respond to perceived risk, policy restrictions, vaccination status, recovery status, and social norms. These endogenous behavioral responses can shape mobility and, in turn, contagion patterns.

The chapter argues that ignoring such feedback limits the usefulness of agent-based models for policy analysis. It presents a proof of concept for incorporating inverse reinforcement learning into an urban agent-based model. Observed mobility behavior is used to infer reward structures, and those learned rewards are then used to generate agent routines inside the simulation.

The chapter explains how the ABM environment, state space, and behavioral procedures need to be configured so the learned model can interact with disease dynamics. It also discusses the practical challenge of defining activity locations, route-like routines, and movement decisions in a way that remains compatible with contagion processes. The contribution is both conceptual and methodological.

Conceptually, it shows why behavioral learning is essential for modeling urban crises in which people adapt to changing conditions. Methodologically, it outlines how data-driven learning can be embedded in an ABM workflow, moving beyond fixed heuristics toward agents whose mobility behavior is inferred from empirical evidence.
