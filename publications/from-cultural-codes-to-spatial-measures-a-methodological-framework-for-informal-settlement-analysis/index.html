Summary

This paper develops a methodological framework for translating culturally grounded spatial principles into measurable spatial indicators. It begins from the observation that informal settlements are often described as chaotic, even though many are shaped by internal cultural orders, social relations, and shared spatial codes. The paper asks how such qualitative cultural-spatial knowledge can be translated into a form that supports systematic spatial analysis without stripping away its interpretive meaning.

Using Bedouin informal settlements in the Israeli Negev as a case study, the article formalizes components of the Bedouin Spatial Code and operationalizes them through GIS and morphological analysis. The workflow moves from code descriptions to spatial indices, measurable relations, and implementation using geodata. The resulting measures make it possible to evaluate adherence to individual code components and to combine them into broader indicators of cultural-spatial order.

The paper shows that Bedouin informal settlements exhibit structured spatial patterns that persist despite forced relocation, planning pressure, and external intervention. It also distinguishes between code components that are strongly tied to physical geography and those that are more socially flexible. This distinction matters for planning because it helps identify which spatial-cultural principles may be more adaptable in locally sensitive interventions.

The broader contribution is methodological and conceptual: it demonstrates how geoinformatics can support cultural geography when quantitative measures are built from qualitative cultural interpretation rather than imposed independently of it.
